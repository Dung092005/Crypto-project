Tectonic 0.17.0 ran BibTeX and repeated TeX automatically until references and TOC stabilized. From the repository root in this Windows workspace, create the sibling r05-build directory, run Tectonic from report/, and copy its main.pdf to report/BroadcastGuard_8_Page_Review.pdf. The exact commands executed were:

    New-Item -ItemType Directory -Path ..\r05-build -Force | Out-Null
    $env:HTTP_PROXY=''; $env:HTTPS_PROXY=''; $env:ALL_PROXY=''
    Push-Location report
    & '..\..\r02-tools\tectonic.exe' -k --keep-logs -o ..\..\r05-build main.tex
    Pop-Location
    Copy-Item ..\r05-build\main.pdf report\BroadcastGuard_8_Page_Review.pdf

r02-tools is a local compiler location, not a repository dependency. An installation of Tectonic or XeLaTeX plus the fonts and packages is needed on another machine.
