# BroadcastGuard reproducibility

This guide reproduces the **analysis of existing evidence**. It does not regenerate the original random RSA keys, OAEP ciphertexts or AES material. The official raw run is immutable: `official-20261106T083221Z-3bbf57cc`, generated by source commit `46c455819e4588736d4777c252d844fa03e7caf3`. Its manifest records Windows 11, Python 3.12.10, `cryptography` 48.0.1, Intel64 Family 6 Model 191 Stepping 2, 20 logical CPUs, 20 measured repetitions and two E3 warmups. The schedule seed governs run order only, never cryptographic randomness.

## Clean Python environment

Python 3.12 is the verified version; `pyproject.toml` supports Python 3.11+. From the repository root on Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev,analysis]"
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe -m pytest -q
```

On macOS/Linux, use `python3.12 -m venv .venv` and `.venv/bin/python`. The analysis extra is local tooling; Streamlit Cloud's runtime requirements do not include Matplotlib. Dependency ranges permit newer compatible releases, so record actual versions when repeating verification. The committed official measurements retain their original 2026 environment; rerunning tests under a newer dependency set does not change them.

## Verify and regenerate without new measurements

```powershell
.\.venv\Scripts\python.exe -m experiments.run_experiments --validate-only docs/evidence/official-20261106T083221Z-3bbf57cc
.\.venv\Scripts\python.exe -m analysis.run_analysis --input docs/evidence/official-20261106T083221Z-3bbf57cc --output docs/analysis
.\.venv\Scripts\python.exe -m compileall -q app.py app_pages broadcastguard experiments analysis examples tests
```

The validator checks schemas, row counts, case coverage, same-key pairing, statuses, timing/overhead consistency, secret markers and `summary.json` recomputation. The analysis CLI refuses a missing, malformed or wrong-run dataset before making tables or figures. It writes six CSV tables and Figures 1–4 as 300-DPI PNG and SVG. Numeric tables are derived from the raw CSVs; graphical rendering may vary slightly with Matplotlib/font versions. Figure 3 uses separate zero-based Y scales for 10 KiB, 100 KiB and 1 MiB, as stated in its title and caption. No cryptographic benchmark runs during import or figure regeneration.

For a non-destructive comparison, choose a fresh directory outside the repository, for example `..\task10-analysis-check`, as `--output`. Compare its six CSV tables with `docs/analysis/tables/`. The raw official CSVs under `docs/evidence/` must never be edited to improve a plot or remove an outlier. Running `--mode official` would produce a **new** independent dataset with different keys, ciphertexts and timing; it is unnecessary for reproducing these figures.

Run the seven CLI examples from `examples/` if checking the educational flows. Streamlit's `tests/test_attack_ui.py` and `tests/test_defense_ui.py` are included in the full pytest command. The application entrypoint remains `app.py`; no part of this guide deploys it.
